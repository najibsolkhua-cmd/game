# 🏢 Холдинг — карточная бизнес-игра

Браузерная карточная игра на 2–4 игрока: **1 на 1** с ботом, **вчетвером** (вы и 3 бота), **за одним экраном** (2–4 человека передают устройство по кругу) или в любом составе людей и ботов.

Собирайте компании из четырёх этапов (Сырьё → Производство → Склад → Транспорт) в химической, лесной или строительной отрасли и продавайте их картой «Продажа». Торгуйте картами **вслепую** на аукционе (с блефом), берите кредиты, покупайте акции компаний соперников, отбивайтесь от налоговой юристом и подстраивайтесь под события рынка: кризис, госзаказ, санкции.

Управление — **перетаскиванием карт** (мышь или палец), всё помещается на одном экране: компьютер, планшет, телефон.

**Правила:** [RULES.md](RULES.md) (они же есть в самой игре, кнопка «Правила»).

## Как запустить

Сборка не нужна, достаточно открыть `index.html` в браузере. Можно и через локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте http://localhost:8000. Если в настройках репозитория включить GitHub Pages (ветка `main`, корень), игра будет доступна по ссылке `https://najibsolkhua-cmd.github.io/game/`.

## Управление

| Перетащите | Куда | Что произойдёт |
|---|---|---|
| Этап / универсальную | в свою компанию | Построить (бесплатно) |
| «Продажу» | на собранную компанию | Продать компанию |
| Любую карту | на 🔨 | Аукцион вслепую |
| Любую карту | на соперника | Предложить сделку |
| «Налоговую» | на соперника | Проверка его стола |
| «Акцию» | на компанию соперника | Вложиться и получить долю |
| Колоду | в руку | Купить карту за $3 |
| Карты соперника | в руку | Купить у него карту вслепую |

Нажатие на карту увеличивает её (там же есть кнопки действий), нажатие на заголовок компании показывает расшифровку цены. Кредит берут кнопкой 🏦. Журнал сделок справа, на телефоне — кнопка 📜.

## Структура

```
index.html          — разметка и текст правил
css/style.css       — оформление (адаптив под телефон)
js/cards.js         — колода: 54 карты + рубашка
js/engine.js        — игровой движок (без UI, работает и в Node)
js/ai.js            — боты: сбалансированный, торговец, акула, осторожный
js/ui.js            — интерфейс, диалоги, режим «за одним экраном»
assets/cards/*.svg  — арт карт (оригинальные + новые: юрист, акция, события, рубашки)
assets/table/*.svg  — узор стола (гильош)
tools/make_cards.py — генератор новых карт в стиле колоды (текст в кривых, шрифт Montserrat Alternates, OFL)
sim/simulate.js     — балансная симуляция бот-против-бота
```

## Баланс

Параметры подобраны симуляцией: `node sim/simulate.js 400` прогоняет 400 партий ботов на каждое число игроков.

| Игроков | Цель | Длина партии (раундов, медиана) | Победы по местам |
|---|---|---|---|
| 2 | $45 | 14 | 54% / 46% |
| 3 | $40 | 11 | 31% / 33% / 36% |
| 4 | $35 | 9 | 21% / 24% / 27% / 28% |

Все числа (цены, кредит, доля акции, бонусы, цели) собраны в `DEFAULT_RULES` в `js/engine.js`.
