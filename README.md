# 🏢 Холдинг — карточная бизнес-игра

Браузерная карточная игра на 2–4 игрока: **1 на 1** с ботом, **вчетвером** (вы и 3 бота), **за одним экраном** (2–4 человека передают устройство по кругу) или в любом составе людей и ботов.

Собирайте компании из четырёх этапов (Сырьё → Производство → Склад → Транспорт) в химической, лесной или строительной отрасли, продавайте их картой «Продажа», торгуйте картами **вслепую, по рубашке** (с возможностью блефа) и натравливайте «Налоговую» на конкурентов.

**Правила:** [RULES.md](RULES.md) (они же есть в самой игре, кнопка «Правила»).

## Как запустить

Сборка не нужна, достаточно открыть `index.html` в браузере. Можно и через локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте http://localhost:8000. Если в настройках репозитория включить GitHub Pages (ветка `main`, корень), игра будет доступна по ссылке `https://najibsolkhua-cmd.github.io/game/`.

## Управление

- **Клик по карте на руке** выбирает её, над рукой появляются действия: построить, продать банку, предложить игроку, сыграть.
- **Двойной клик по этапу** сразу выкладывает его в компанию.
- **Клик по колоде** — купить карту в тёмную за $3.
- **Клик по любой открытой карте** на столе — увеличить её.
- Справа ведётся **журнал сделок**: что делали соперники.

## Структура

```
index.html          — разметка и текст правил
css/style.css       — оформление (адаптив под телефон)
js/cards.js         — колода: 54 карты + рубашка
js/engine.js        — игровой движок (без UI, работает и в Node)
js/ai.js            — боты: сбалансированный, торговец, акула, осторожный
js/ui.js            — интерфейс, диалоги, режим «за одним экраном»
assets/cards/*.svg  — арт карт
sim/simulate.js     — балансная симуляция бот-против-бота
```

## Баланс

Параметры подобраны симуляцией: `node sim/simulate.js 400` прогоняет 400 партий ботов на каждое число игроков.

| Игроков | Цель | Длина партии (раундов, медиана) | Победы по местам |
|---|---|---|---|
| 2 | $50 | 12 | 51% / 49% |
| 3 | $45 | 10 | 36% / 32% / 32% |
| 4 | $40 | 8 | 25% / 25% / 29% / 22% |

Партия вдвоём занимает 15–20 минут, ни один стиль ботов не доминирует. Все числа (цены, лимиты, цели) собраны в `DEFAULT_RULES` в `js/engine.js`, их легко менять.

## Идеи, как сделать игру интереснее

1. **Карты событий рынка** («Кризис»: все компании дешевеют на $3 в этом раунде; «Госзаказ»: стройка +$5; «Санкции»: химию нельзя продавать). Открывается одна карта в начале раунда, и вокруг неё меняется вся стратегия.
2. **«Юрист» / «Аудит»** — защитная карта: отменяет налоговую или возвращает изъятую карту. Даёт защиту от самой агрессивной механики.
3. **Синергия отраслей.** Стройке нужна древесина: если у вас одновременно есть лесная и строительная компании, продажа стройки приносит +$3. Химия даёт бонус лесу (пропитка) и так далее.
4. **Аукцион вслепую.** Вместо продажи банку карту можно выставить на торги рубашкой вверх: соперники делают закрытые ставки.
5. **Кредит в банке.** Взять $10 сейчас и вернуть $13 через 3 хода; не вернул — банк изымает этап.
6. **Акции чужих компаний.** Вложить $5 в компанию соперника и получить 20% от её продажи. Появляется кооперация между конкурентами.
7. **Уникальные роли игроков** («Олигарх» начинает с +$5, «Логист» может класть транспорт любой отрасли, «Аудитор» видит одну карту соперника в начале хода).
8. **Сеть.** Онлайн-мультиплеер через WebSocket (комнаты по коду) вместо игры за одним экраном.
9. **Рейтинг, достижения и обучение** («Чистый бизнес», «Монополист» за компанию из одних +3, «Блефёр» за продажу мусора с заявкой «Продажа»).
10. **Физическая версия.** Правила полностью подходят для печатной колоды: нужны только карты и бумажные деньги.
